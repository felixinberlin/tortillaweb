## 2024-03-24 - Localized Navigation ARIA Attributes
**Learning:** Disclosure patterns in mobile menus often default to English ARIA labels (`aria-label="Toggle Navigation Menu"`, `aria-label="Close menu"`, `aria-label="Toggle submenu"`) even when an application relies heavily on i18n for text. This creates a mismatched experience for screen reader users in other languages. Furthermore, linking these toggle buttons via `aria-expanded` and `aria-controls` to the content IDs is crucial for conveying relationship and state.
**Action:** When adding or auditing complex navigation components with drop-downs/drawers, ensure we replace hardcoded English strings with dynamic translations (e.g., `lang === 'es' ? 'Abrir menú' : 'Open menu'`), dynamically track `aria-expanded={isOpen}`, and explicitly bind `aria-controls` to the actual `id` of the matching container element.
